# proyectoFinal_Equipo1 - Hogarea

Gestor de tareas del hogar - Aplicaciones Móviles, ITSON.

Mock up en Figma: https://www.figma.com/design/wPXTFT53iTf7HG2pj1DfbD

## Integrantes, caso de uso individual y rama

| Integrante     | Caso de uso individual | Rama |
|----------------|---|---|
| Freddy         | Configurar el hogar | freddy/configurar-hogar |
| Rubén | Crear y editar tareas | ruben/crear-editar-tarea |
| Ángel | Detalle de tarea: completar, pausar y eliminar | angel/detalle-tarea |
| André | Estadísticas | andre/estadisticas |

## Partes colaborativas

- Mis tareas (lista semanal): Rubén y Ángel
- Crear o unirse a un hogar: Ángel y André
- Acceso (login, huella, recuperar contraseña y registro): Rubén y André
- Perfil y modo oscuro: Rubén y André
- Extras (notificaciones, puntos e historial): Ángel y André
- Base del proyecto: Freddy

## Cómo ejecutarlo

1. Clonar el repositorio y cambiar a la rama `frontend`.
2. Abrirlo en Android Studio y ejecutarlo en un emulador.
